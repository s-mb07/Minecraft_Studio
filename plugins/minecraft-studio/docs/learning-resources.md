# Learning resources: Blockbench modelling, pixel-art texturing, animation

This list came from a research digest. The links are listed for further reading and **haven't been re-checked one
by one**. Prefer the official docs, and treat old GeckoLib videos (1.18 / Forge) as Blockbench-only references:
their Java code doesn't transfer to NeoForge 1.21.1. The verified facts used by the skills are in mc-geckolib.

## Official
- Blockbench wiki, overview and tips (Edit / Paint / Animate modes): https://blockbench.net/wiki/guides/blockbench-overview-tips/
- Blockbench wiki, Bedrock modelling and animation: https://blockbench.net/wiki/guides/bedrock-modeling/
- Microsoft Learn, Getting started with Blockbench: https://learn.microsoft.com/en-us/minecraft/creator/documents/blockbench
- Bedrock Wiki, Blockbench modelling, texturing, animating: https://wiki.bedrock.dev/guide/blockbench
- GeckoLib wiki, Blockbench plugin: https://wiki.geckolib.com/docs/geckolib5/making-models/blockbench-plugin-usage/
- Mojang/bedrock-samples (vanilla `.geo.json`, textures, animations to study): https://github.com/Mojang/bedrock-samples

## Tutorials
- Blockbench Workshop tutorials (pixel art, brick block, creature animation, seamless, outlines): https://blockbenchworkshop.com/tutorials
- "Blockbench w/ GeckoLib" #1 model, #2 texture, #3 animation (2022, Blockbench parts still valid)
- CurseForge Academy, "Model a mob in 10 minutes" (2026, GeckoLib)
- Kaupenjoe, NeoForge + GeckoLib mob with a special attack (2026)

## Community
- r/Blockbench: feedback on silhouette, UV and animation. Useful threads: animating groups vs cubes, putting a
  mob in Minecraft (Bedrock/CEM vs Java mod), opening vanilla mobs, Blender vs Blockbench (Blockbench is enough
  for mobs, blocks and items; Blender is for advanced renders).

## Automation
- jasonjgardner/blockbench-mcp-plugin (tools, headless): https://github.com/jasonjgardner/blockbench-mcp-plugin
- jasonjgardner/blockbench-mcp-project (example project): https://github.com/jasonjgardner/blockbench-mcp-project
